# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是三个端里要第一个启动的。代码在 `server` 文件夹。接口文档标题是「旅游攻略系统接口文档」。

## 开始之前要准备什么

在自己的 Windows 电脑上安装下面的软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 8.0 及以上 | 开始菜单里能找到 MySQL Command Line Client |

Java 不要装成 11、17 或 21。装错版本时，先卸掉，再装 1.8。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

Maven 下载：https://maven.apache.org/download.cgi 。解压后把里面的 `bin` 文件夹加到 PATH。关掉原来的 PowerShell，再打开一个新的，`mvn -v` 才能看到版本。

MySQL 安装过程中会让你给 `root` 设一个密码，还会让你确认端口。把密码和端口记下来。Windows 上新装的 MySQL，端口通常是 **3306**。

Redis 当前默认是关着的。打开 `server/sqx-application/src/main/resources/application.yml`，`sqx.redis.open` 是 `false`。按本教程启动时，不必先装 Redis。以后如果把开关改成 `true`，再安装 Redis，地址用 `127.0.0.1`，端口 `6379`。

## 第 1 步：新建空数据库

库名是 `lvyougonglve`。要先建库，再导入 SQL。

1. 打开 MySQL 命令行，输入 root 密码，看到 `mysql>`。
2. 执行：

```sql
CREATE DATABASE IF NOT EXISTS lvyougonglve DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

3. 再执行 `SHOW DATABASES;`，列表里有 `lvyougonglve` 就成功。输入 `exit` 退出。

## 第 2 步：导入数据库文件

文件位置（相对整个项目文件夹）：

`server/db/lvyougonglve.sql`

这是开源演示库：含完整表结构和演示数据，**不含真实用户隐私与第三方密钥**。后台账号是 `admin` / `123456`。导入会覆盖同名表，请导入到上一步新建的空库。

在项目根目录打开 PowerShell。把 `-p` 后面的密码、`-P` 后面的端口改成你的 MySQL：

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -p123456 -P3306 --default-character-set=utf8mb4 -e "source $($PWD.Path -replace '\\','/')/server/db/lvyougonglve.sql"
```

用 Navicat 也可以：连接到本机 MySQL，菜单选「运行 SQL 文件」，选中 `server/db/lvyougonglve.sql`，编码选 UTF-8。脚本里已包含建库语句，也可以直接运行整份文件。

## 第 3 步：让程序连接你自己的 MySQL

本仓库有两份数据源配置：

| 文件 | 默认连哪里 |
|---|---|
| `server/sqx-application/src/main/resources/application-dev.yml` | 本机 `127.0.0.1:3306/lvyougonglve`，用户 `root`，密码 `123456` |
| `server/sqx-application/src/main/resources/application-prod.yml` | 线上地址（不要直接拿来本机跑） |

本机调试建议改 `application.yml`：

```yaml
spring:
  profiles:
    active: dev
```

再打开 `application-dev.yml`，把端口和密码改成和你电脑一致：

```yaml
url: jdbc:mysql://127.0.0.1:3306/lvyougonglve?useUnicode=true&characterEncoding=utf-8&useSSL=false
username: root
password: 123456
```

只改端口和密码；库名保持 `lvyougonglve`。

## 第 4 步：启动服务端

在 `server` 文件夹里打开 PowerShell，执行：

```powershell
mvn clean package -DskipTests
mvn spring-boot:run
```

第一次会下载很多依赖，窗口要一直开着。看到 Spring Boot 启动完成、没有连库失败，就算成功。

用 IDEA 也可以：

1. 用 IDEA 打开 `server`（选有根 `pom.xml` 的那一层）。
2. 等 Maven 导入结束。Project SDK 选 1.8。
3. 安装 Lombok 插件，并勾选 Enable annotation processing。
4. 打开 `sqx-application/src/main/java/com/sqx/SqxApplication.java`，点左侧绿色三角启动。

## 怎样算成功

浏览器打开：

http://127.0.0.1:9097/sqx_fast/doc.html

能看到 Knife4j 接口文档，标题附近是「旅游攻略系统接口文档」。

服务端端口是 **9097**，上下文路径是 `/sqx_fast`。

后台登录账号以导入库里的演示账号为准，常见为 `admin` / `123456`。短信、微信、支付宝、图片存储等密钥需要自己到对应官网申请，再填进管理端系统配置。申请入口写在 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**`java` 不是内部或外部命令，或版本不是 1.8**  
安装 Temurin 8，关掉 PowerShell 再打开，重新执行 `java -version`。

**`mvn` 不是内部或外部命令**  
Maven 的 `bin` 没有加到 PATH。加完后必须关掉 PowerShell 再开一次。

**`Access denied for user 'root'`**  
MySQL 密码和 yml 里的 `password` 不一致。

**`Communications link failure`**  
本机 MySQL 端口和 yml 不一致。Windows 默认多为 3306。

**`Unknown database 'lvyougonglve'`**  
第 1 步建库没有成功。

**`Port 9097 was already in use`**  
关掉之前开着的服务端窗口，或结束占用 9097 的 Java 进程。

**把 Redis 开关打开之后启动失败**  
先启动 Redis，再启动服务端。不打算用缓存时，`sqx.redis.open` 保持 `false`。
