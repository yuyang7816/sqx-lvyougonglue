# 用户端运行教程

按顺序做。这是给手机和网页用的应用，应用名称是「旅游攻略」。用 HBuilderX 打开 `lvyou-uniapp` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 导入数据库并启动服务端。服务端没启动时，页面也许能打开，但列表是空的，登录会失败。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具。

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开 `lvyou-uniapp/common/config.js`。文件里现在可能指向线上域名。改成本机：

```javascript
const ROOTPATH = "http://127.0.0.1:9097/sqx_fast";
const ROOTPATH3 = "ws://127.0.0.1:9097/sqx_fast/"; // 聊天

const config = {
	APIHOST: ROOTPATH,
	WSHOST1: ROOTPATH3
};
export default config;
```

本机用 `ws://`，不要写成 `wss://`。保存文件。

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。
3. 选中 `lvyou-uniapp` 这个文件夹。不要选它的上一级，也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`pages.json`、`manifest.json`、`common`。

## 第 3 步：在电脑浏览器里运行

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到「编译成功」，浏览器会自己打开。
3. 打开后底部应能看到 **首页、攻略群、消息、我的**。

HBuilderX 不要关。关掉后页面会打不开。

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里的小程序 AppId 需要改成你自己的，或继续只用浏览器运行。本地调试可勾选「不校验合法域名」。

## 怎样算成功

首页能打开，底部四个按钮能点。按键盘 `F12`，点「网络」或 Network，再刷新。列表里的请求地址应是 `127.0.0.1:9097`。若仍指向其他域名，说明第 1 步没有保存，或改完后没有重新运行。

库里没有内容时，首页可能是空的。这表示接口已经通了，只是还没有运营数据。用手机号注册需要短信；短信密钥没配时，验证码发不出去。密钥申请见 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**运行菜单是灰的**  
确认打开的是整个 `lvyou-uniapp` 目录，而不是单个文件。

**页面空白、接口失败**  
服务端没启动，或 `common/config.js` 仍指向线上。

**聊天连不上**  
检查 `ROOTPATH3` 是否改成了本机 `ws://127.0.0.1:9097/...`。
