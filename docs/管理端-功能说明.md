# 管理端功能说明

管理端是给平台工作人员用的网站，在电脑浏览器里打开。游客不使用这个网站。它用来看经营数据、维护目的地和景点内容、处理订单和提现，以及填写微信、支付宝、短信、图片存储这些外面服务的账号。

程序基于 Vue 3 + Element Plus。工作人员登录后，左侧是菜单。能看到哪些菜单，由管理员给这个账号分配的权限决定。

下面的模块名称来自当前代码页面；如果你后来在「菜单管理」里改过名字，以你屏幕上看到的为准。

## 登录

登录页要填账号、密码。服务端没启动时，登录会失败。

导入数据库之后，演示账号常见为 `admin` / `123456`。开源使用时建议只使用 `admin`，或在管理员列表里自己新建。

## 数据看板

登录后的 Dashboard / 首页，用来看平台概况，数字来自自己的数据库。

## 用户相关

### 用户列表

看注册用户，可进入用户详情，查看账号、资料、认证等相关信息。

### 注销申请

用户在设置里申请注销账号后，记录出现在这里，由人工处理。

## 内容运营

### 目的地 / 国家地区 / 搜索相关

维护目的地、国家或地区标签、搜索相关运营内容，供用户端首页和搜索使用。

### 景点与旅游产品

维护景点信息、旅游产品等内容，对应用户端景点详情、相关列表。

### 路线 / 课程类内容

若后台有课程或路线类菜单，用于维护精选路线等相关内容。

### 轮播与素材

维护用户端首页或频道用的轮播图、素材资源。

### 动态与店铺

审核或管理用户动态、评论，以及店铺 / 商户相关信息。

## 消息与投诉

查看站内消息、投诉记录，用于客服和风控处理。这不是手机短信。

## 订单与财务

### 订单中心

查看用户订单状态，处理与订单相关的后台操作。

### 财务 / 提现

查看资金流水、提现申请。通过审核不等于已经打款到用户支付宝，具体以你们线下或支付接口流程为准。

### VIP / 优惠券 / 分销配置

维护会员权益、优惠券、邀请分销相关配置。

## 系统管理

### 管理员、角色、菜单

管理后台账号、角色权限、菜单结构。没有权限的菜单不会出现在左侧。

### 系统配置

填写短信、支付、对象存储、客服等外部服务参数。改完保存后，由服务端在下次调用时生效。

## 和用户端的关系

- 管理端改的内容，用户端下次请求才会刷新。
- 用户端上传的认证、投诉、提现，最终都要到管理端处理。
- 管理端不代替用户发短信、付款；真正发短信和收支付通知的是服务端。
