# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `lvyou-admin(旅游1.0-管理端)` 文件夹。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端没启动时，这个网站打得开，但登录会失败。

## 开始之前要准备什么

安装 Node.js 20 或更高版本（项目 `package.json` 的 engines 要求 `^20.19.0 || >=22.12.0`）：https://nodejs.org/

安装时勾选添加到 PATH。安装完成后，重新打开 PowerShell，输入：

```powershell
node -v
npm -v
```

两行都有版本号才算成功。浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

用记事本打开：

`lvyou-admin(旅游1.0-管理端)/comment/httpUrl.js`

改成指向本机服务端：

```javascript
const ROOTPATH = "http://127.0.0.1:9097/sqx_fast";

export {
  ROOTPATH,
}
```

保存。管理端上传地址已跟随 `httpUrl.js` 的 `ROOTPATH`（全局 `$uploadUrl`），一般不用再改页面里的上传地址。

## 第 2 步：安装依赖

在 `lvyou-admin(旅游1.0-管理端)` 文件夹里打开 PowerShell，执行：

```powershell
npm install
```

第一次可能要几分钟。结束时没有红色 `npm ERR!`，并且出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还是在该文件夹里执行：

```powershell
npm run dev
```

默认端口是 **8888**（见 `vite.config.js`）。浏览器打开：

http://localhost:8888

登录页应能正常打开。这个 PowerShell 窗口要一直开着。

## 怎样算成功

能打开登录页，用演示账号登录后能看到左侧菜单和数据页。演示账号常见为 **admin** / **123456**（以导入库为准）。

请求地址应指向 `127.0.0.1:9097`。若仍打到线上域名，说明第 1 步没保存，或改完后没有重启 `npm run dev`。

## 常见问题

**登录提示失败，或接口全红**  
服务端没启动，或 `comment/httpUrl.js` 地址不对。

**`npm` 不是内部或外部命令**  
Node.js 没装好，或没勾选 PATH。重装后必须新开 PowerShell。

**端口 8888 被占用**  
Vite 配置里 `strictPort` 为 false 时会自动换端口，以控制台打印的地址为准。

**Node 版本过低**  
按 `package.json` engines 升级到 Node 20+。
